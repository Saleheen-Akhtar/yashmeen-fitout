# Website Vibe Document

## Source of truth

Yashmeen is a Dubai fit-out partner for considered interiors. The site should make one idea immediately clear: design, approvals, workshop fabrication, MEP and construction are coordinated by one accountable team.

## Audience and goal

The audience is luxury residential, commercial office and hospitality decision-makers in Dubai. The primary goal is a qualified enquiry or quote request.

## Brand

Warm editorial architecture. Use Cormorant Garamond for display, Plus Jakarta Sans for body and UI, warm white and stone surfaces, ink text, muted supporting text and bronze as the single accent. Use thin rules, generous spacing and restrained motion.

## Experience principles

1. State the offer before explaining the company.
2. Prove accountability through process, workshop and case studies.
3. Keep the path to contact visible without making every section a sales pitch.
4. Use specific facts only when they are client-approved and current.
5. Keep forms short and explain the next step.

## Content rules

Use: engineered, manufactured in Al Quoz, accountable, bespoke joinery, turnkey handover, authority approvals.

Avoid: revolutionary, world-class, seamless, elevate, synergy, cutting-edge and unsupported guarantees.

## Current implementation constraints

The existing application is React 19 + Vite with plain CSS, React Router, GSAP/Lenis motion, an Express API and MongoDB. Preserve the existing route structure and admin functionality while improving public-site clarity.
