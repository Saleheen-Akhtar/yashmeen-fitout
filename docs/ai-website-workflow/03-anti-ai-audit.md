# Anti-AI Patterns Audit

## Current strengths

- The homepage has a clear service promise and an obvious quote action.
- The light editorial system is more distinctive than a default dark agency template.
- The process section explains delivery in four concrete stages.
- Contact details and service routes are visible.

## Patterns to monitor and human fixes

| Pattern | Human fix |
| --- | --- |
| Generic claim such as world-class | Use a verifiable facility, discipline or handover fact. |
| Too many boxed cards | Let typography, rules and image composition carry hierarchy. |
| Repeated eyebrow labels | Keep one label per section, only when it adds orientation. |
| Abstract hero copy | Name the work, location and accountability model. |
| Invented social proof | Keep placeholders until the client verifies names and permissions. |
| Decorative numbers | Tie every number to a facility, project history or operating process. |
| Gradient as atmosphere | Use natural image light or a restrained overlay only where needed. |
| Overlong paragraphs | Keep the first read scannable; move detail into project/service pages. |
| Identical section rhythms | Alternate image-led, process-led and proof-led compositions. |
| Form with no reassurance | State what happens after submission and response timing. |

## Priority audit findings

1. Verify all proof claims and testimonials before publishing them as facts.
2. Keep the homepage focused on one conversion path: enquiry/quote.
3. Reduce any filler copy that repeats the same accountability message.
4. Check every image has meaningful alt text and a fallback.
5. Preserve the current motion restraint and reduced-motion support.
