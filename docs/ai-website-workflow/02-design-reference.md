# Design Reference

## Reference used

The existing implementation and `BRAND_BRIEF.md` are the working references. No external reference URL was supplied with this workflow.

## Design language to preserve

- Light editorial architecture: warm paper surfaces, restrained bronze, thin rules and generous whitespace.
- Serif display headlines paired with a modern sans-serif for navigation, body copy and form controls.
- Photography carries atmosphere; text remains short and specific.
- Sections use strong editorial headings, clear left alignment and one primary action.
- Portfolio content should feel curated rather than a dense catalogue.

## Mapping to Yashmeen

- Hero: single-source accountability, one clear quote action and a real built-space image.
- Services: four accountable service families with a practical one-line outcome each.
- Portfolio: projects, gallery and proof of craft.
- Process: brief, approvals, parallel workshop/site delivery, handover.
- Contact: direct phone/email/address plus a short enquiry form.

## Avoid

Generic SaaS cards, excessive gradients, dark UI for every section, vague claims, repeated eyebrow labels, fake metrics and decorative UI with no conversion job.
