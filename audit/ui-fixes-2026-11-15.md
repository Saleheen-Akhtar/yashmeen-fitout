# Public UI fixes

The homepage and subpages now share the same light header and 44px menu button. The contact bar is replaced by one floating WhatsApp icon. The project carousel inherits the section canvas, with no black wrapper or stage background.

The public palette now resolves to tokens.css instead of competing root overrides. Founder, Why Us and project-detail selectors are scoped to their pages. Small labels use at least 12px, gallery controls use larger touch targets, and the header has consistent content clearance. The testimonial panel and cookie banner use the warm light palette. Cookie-banner height is measured so WhatsApp remains above it. Mobile enquiry errors stay visible in the modal footer.

Validation: production build and prerender passed; ESLint and TypeScript passed; 43 frontend tests passed. The Windows test runner required normal process access after sandbox spawn EPERM. Modified files pass git diff --check.

Browser scan: 17 public routes at 1440px, 768px and 375px, with no document horizontal overflow or visible main-content labels below 12px after the fixes. Verified menu close and focus restoration, SPA menu navigation, carousel arrow-key selection, cookie/WhatsApp separation, and empty enquiry, quote and contact validation. A fresh homepage browser session had no captured console warnings or errors. No successful forms were submitted.
