# Wireframe Decisions

The existing site is the locked baseline for this pass. The workflow's three-option selection step is recorded here so the implementation remains reviewable.

| Section | Selected direction | Reason |
| --- | --- | --- |
| Hero | Editorial split: offer left, built-space image right | Converts quickly while showing craft. |
| Services | Four linked rows with concise outcomes | Avoids card-grid sameness and supports service navigation. |
| Portfolio | Curated interactive gallery | Gives visual proof without a dense catalogue. |
| Process | Four sequential stages | Makes delivery logic easy to understand. |
| Contact | Direct details plus compact form | Lowers friction and sets response expectation. |
